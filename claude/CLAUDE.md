# CLAUDE.md

## 応答スタイル

- 回答の中に「確信を持って言えること」と「推察・推測したこと」が混在する場合は、明確に分けて記述する（例:「確実な情報」「推測される情報」のように見出しや箇条書きで区別する）
- ユーザーからの入力が日本語以外の言語であっても、回答は必ず日本語で行う
- 修正・変更などを明示的に指示しない質問（調査・確認・説明を求める質問など）に対しては、ファイルを変更しない

## ローカルDB調査

- ローカル環境のDBを調査する際は、DBコンテナ内で `mysql` / `psql` コマンドを実行して行う
- ローカルDBは読み取り専用として扱う。データの変更・追加・削除（INSERT/UPDATE/DELETE/DDLなど）を行うクエリは実行しない

## 調査方針

- ライブラリ・フレームワーク・SDK・API・CLIツールなどの調査が含まれる場合は、必ず context7 を使用する

## 設計方針

- 設計を提案する際は、対象プロジェクトの既存の記述方法・慣習に従った案だけでなく、一般的なベストプラクティスに基づく案もあわせて提示する

## 実装方針

- 実装したコードは、明示的に指示されるまでコミットしない（git commit / amend / push は行わない）
